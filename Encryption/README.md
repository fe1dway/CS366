# Encryption Project

In this project, you will be implementing an encrypted echo server and client. All of your code will live in `Echo/EncryptedEchoClient.cs` and `Echo/EncryptedEchoServer.cs`. Feel free to look at the other files to get a sense of how the echo server works, but you should not change any of these files.

## Running

From within the echo directory,
* To run the server, use `dotnet run server`
* To run the client, use `dotnet run client`

## Testing

To help you test your code, I've provided reference implementations of the encrypted echo server and client: `echo-test`.
To test your client-side functionality, run it against the reference server.
To test your server-side functionality, run it against the reference client.
If you are using an arm device (like the mac M1--M4) use `echo-test-arm`.
